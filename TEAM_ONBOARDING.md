# CrownOps team handoff

Each person uses an individual CrownOps account. Installing an icon gives quick access to the hosted web app; it does not create an account, grant new permissions or allow offline work.

## Assign the remaining work

| Person / access | Work to finish | Evidence of completion |
| --- | --- | --- |
| Owner | Separate logins, crew-to-employee links, active staff/pay rates, verified drivers, policy approvals, provider settings and final launch review | Owner checks the Launch checklist and reviews the complete test booking |
| Manager / Dispatch | Shared contacts, truck registration/specifications/current readings, exact inspection expiry, repair follow-ups, reviewed activation and test assignments | Truck documents and repair notes checked; test crew/truck assigned with current pre-use check |
| Sales | A labelled TEST client/quote with correct inventory, access, date, crew/trucks and charges | Reviewed quote and accepted test workflow checked with dispatch |
| Crew member | Own login, assigned job/instructions, shared contacts, actual pre-use check and TEST hours/material entries | Manager verifies the record and the phone layout |
| Accounting | Issuer/tax details, invoice actuals/minimum/materials/deposit credit, time/period review and QuickBooks mappings | Owner confirms totals; TEST payroll remains unapproved |

An employee's job title is separate from account access. Give the manager Dispatch access for these operational edits. Keep owner-level security, payroll-rate and provider approvals with the owner. A directory import does not create staff logins.

## Add the CrownOps icon

Open the company app address and sign in. Use **Help & install** inside CrownOps for the current instructions.

- Samsung / Android: Chrome's menu offers **Install and create shortcut**, then **Install**. Some versions say **Install app** or **Add to Home screen**. Samsung Internet also provides a home-screen shortcut.
- iPhone / iPad: use Safari's share sheet to add the site to the Home Screen. Enable **Open as Web App** if available and finish adding it.
- Mac: Safari on macOS Sonoma 14 or later can add the site to the Dock from its File menu. Older Macs can use the browser tab or a bookmark.
- Windows / desktop Chrome: use the install control or look under the browser's **Cast, save and share** menu for the app installation option.

If a browser does not offer installation, keep using its normal tab. Internet is required. Sign in again if the newly installed app asks for your account.

## Real-device acceptance check

Assign one tester on a Mac, one on a Samsung/Android phone and one on an iPhone/iPad if those devices are used by the team. Also test a Windows computer if used. Record each tester's device, OS, browser version, role and result.

1. Sign in with the tester's own account, open the navigation menu and find Important contacts.
2. Search a contact, check that the telephone link is correct and that the call action is visible.
3. Confirm office access to Fleet and editing controls appropriate to the role. Crew should use assigned trucks and jobs rather than the office fleet directory.
4. Open the labelled TEST job and a long note or form. Scroll to every action; check that no button is cut off. Verify a permitted test update persists after reopening the screen.
5. Check the assigned truck and current pre-use workflow. Resolve real defects; never record an invented check or repair just to clear a warning.
6. Sign out and sign in again. Never share account passwords. Confirm owner-approved MFA where applicable.
7. Finish the quote/deposit/dispatch/actuals/invoice acceptance test. Review provider environments, mappings and a backup restore before real bookings.

Local browser viewport checks are useful but do not certify a physical Mac, Samsung, iPhone or each browser version. Record actual device results before calling the team rollout verified.

## Brand and source protection

See PROPRIETARY_NOTICE.md. Keep the repository and hosting administration private; give operational users app accounts instead of source access. The copyright notice and app icon do not establish registration or prove ownership. Ask an IP lawyer to review contributor/AI authorship, assignments and confidentiality agreements and to advise on copyright registration for qualifying work and trademark clearance/registration for the name and logo.
